# KHOJ - Home Services Discovery Platform
## Project Report Reference (Condensed Version)

### 1. Student & Project Details
* **Semester**: 7th Semester (School of Engineering)
* **Project Title**: **Khoj — An Intelligent Discovery and Analytics Platform for Home Service Providers**
* **Type**: User Defined Project (UDP)
* **Technology Stack**: MERN (MongoDB, Express, React, Node.js), Tailwind CSS, Ant Design, Recharts, JWT.

### 2. Problem Statement & Objectives
Finding verified local service providers (plumbers, cleaners, etc.) is highly fragmented. Independent merchants also lack a free platform to showcase their skills.
* **Objective**: Build a responsive, glassmorphic React platform with location-based filtering, density visualization (charts), and secure role separation (User vs. Merchant).

### 3. Proposed Methodology
A 3-tier MERN architecture:
* **Frontend**: React SPA styled with custom Tailwind gradients and glassmorphism.
* **Backend**: Node.js & Express.js REST APIs with JWT session authentication.
* **Database**: MongoDB using Mongoose schemas for services, users, and locations.

### 4. Expected Outcomes & Future Scope
* **Outcomes**: A responsive discovery portal, custom dashboards for service providers, and density mapping.
* **Future Scope**: Real-time provider chat (WebSockets), live map integration, and rating systems.

### 5. Tasks & Learnings
* **Accomplished**: Base architecture setup, route and metadata configurations, visual redesign using custom gradients/Outfit fonts, glassmorphism templates, and database error boundaries.
* **Learnings**: Component-driven design, API integration, session management.
