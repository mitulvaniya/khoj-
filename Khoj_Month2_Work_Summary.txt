4. IMPLEMENTATION & TECHNICAL DETAILS
================================================================================
- Algorithm / Method Followed: 
  1. State Machine Pattern: Governs booking transitions (Pending -> Confirmed -> Completed / Cancelled).
  2. Mongoose ReadyState Connection Check: Validates DB readyState before querying; uses in-memory RAM fallback stores when cloud database latency occurs to serve responses in <60ms.
  3. Spatial Offset Algorithm: Generates localized latitude/longitude offsets for Leaflet map markers around Surat, Gujarat (21.1702 N, 72.8311 E).

- Coding / Development Details:
  - Express.js API Gateway with REST endpoints mounted under /v1/ (services, categories, bookings, city, state).
  - Component-driven SPA in React with reusable components (ServiceDetail, MyBookings, AllService, Reviews, AddService, AddCategory, Profile, Setting).

- Database Design:
  - Normalised MongoDB document collections: Users, Services, Categories, Cities, States, Bookings (userId, serviceId, serviceName, bookingDate, timeSlot, notes, address, status), and Reviews.

- API Integration:
  - Booking REST API endpoints, Leaflet tile layers, and Razorpay checkout API integration (in progress, debugging order creation flow and webhooks).

- Testing Performed:
  - Manual verification of authentication, Booking CRUD, duplicate booking prevention (returns 409 Conflict), readyState RAM failover speed (<60ms), and Leaflet map rendering.

5. TECHNICAL CHALLENGES FACED & SOLUTIONS APPLIED
================================================================================

[CHALLENGE 1] Preventing double-booking under concurrent service requests
- Solution Applied: Implemented backend duplicate query validation checking (userId, serviceId, bookingDate, timeSlot) for non-cancelled bookings, returning HTTP 409 Conflict paired with a 3-step date-picker wizard.

[CHALLENGE 2] Mongoose 10-second buffer timeout during cloud database latency
- Solution Applied: Implemented readyState connection checks (if mongoose.connection.readyState === 1) across backend controllers. If the database is disconnected or slow, requests immediately utilize RAM memory fallbacks, serving API responses in <60ms.

[CHALLENGE 3] Leaflet.js double-mounting & 0px map container height in React StrictMode
- Solution Applied: Maintained map container ref permanently mounted in DOM, added mapRef.current.remove() cleanup logic, and triggered mapRef.current.invalidateSize() inside a 300ms post-mount timer.

[CHALLENGE 4] Errors occurring during Razorpay checkout/order creation while integrating payments
- Solution Applied: Currently debugging by checking API request/response payloads, order and payment signature verification, and webhook handling — fix in progress, to be completed and reported next.
