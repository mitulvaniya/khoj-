  - /v1/services: Full CRUD endpoints supporting regex search, rating filtering, and locality bounds.

• Database integration:
  MongoDB Atlas multi-tenant cluster connection managed via Mongoose 8.3. Connection pooling includes a 3000ms timeout tolerance with automated in-memory mock fallback. This ensures the platform never crashes or displays white screens even during external cloud network latency. Schemas include strict validations, indexing on service name/category, and timestamps.

• Hardware integration:
  Mobile/Desktop GPS Geolocation hardware integration using the HTML5 Navigator Geolocation API (navigator.geolocation.getCurrentPosition). The device coordinates (latitude and longitude) are mathematically parsed via the Haversine formula to compute geodesic distances to service provider workshops in real-time.

  - Netlify Edge Network: Continuous hosting and automated asset compression (Gzip/Brotli).
  - Render Cloud Platform: Linux container orchestration running Node.js 20.11 runtime.

Brief Explanation:
The platform utilizes a decoupled, high-performance Jamstack and micro-backend cloud architecture. The React user interface is distributed across Netlify's globally replicated edge points of presence (PoPs), guaranteeing sub-50ms First Contentful Paint (FCP) anywhere in India. API calls made by the client targeting '/v1/*' are captured by Netlify's edge reverse-proxy engine and forwarded securely over TLS to the containerized Express backend running on Render. The Express API validates payloads, enforces role-based authorization, executes business logic, and queries the managed MongoDB Atlas replica set over encrypted TLS sockets. In the event of network disruption, the backend automatically transitions to an in-memory replica so operations never freeze.
