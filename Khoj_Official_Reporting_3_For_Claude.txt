Brief Explanation:
The architecture utilizes a modular, decoupled full-stack paradigm. The frontend is built with React 18 and Ant Design 5, communicating with an Express.js REST API server. The backend features strict Role-Based Access Control (RBAC) middleware guards protecting Super Admin routes, cryptographic HMAC-SHA256 payment verification for Razorpay, and MongoDB database persistence.
